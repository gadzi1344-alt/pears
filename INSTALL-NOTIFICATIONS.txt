PEAR — УВЕДОМЛЕНИЯ И ОТВЕТЫ

1. Открой Supabase → нужный проект → SQL Editor → New query.
2. Открой файл 9-notifications-replies.sql из архива, скопируй всё содержимое в SQL Editor и нажми Run. Выполняй в существующем проекте Pear (где уже созданы profiles, posts, likes, comments и follows). Старые schema.sql и другие SQL-файлы запускать заново не нужно.
3. Открой GitHub-репозиторий Pear. В корень проекта загрузи с заменой app.js и style.css, а также новый файл notifications.js. Не удаляй остальные файлы сайта. По желанию можно загрузить SQL-файл для хранения.
4. Дождись автоматического деплоя на Vercel, затем обнови страницу сайта. Если изменения не появились, обнови страницу с очисткой кеша.

Как проверить: войди в два разных аккаунта. От имени одного поставь лайк, подпишись и напиши комментарий к посту другого. У получателя открой колокольчик: будут показаны уведомления и число непрочитанных. Нажми уведомление, чтобы перейти к посту или профилю и отметить его прочитанным. Можно отметить все прочитанными. Нажми «Ответить» под комментарием и отправь ответ — автор комментария получит уведомление.

Уведомления появляются только для новых действий после установки SQL. История до установки не переносится. Реалтайм используется при доступности Supabase Realtime; иначе данные обновляются примерно раз в 15 секунд, пока сайт открыт. Это уведомления внутри сайта, не push на телефон. Показаны последние 80 уведомлений, а счётчик учитывает все непрочитанные. При удалении лайка, подписки, поста или комментария связанное уведомление может исчезнуть. При удалении исходного комментария его ответы тоже удаляются.

Функции и права доступа проверены на тестовой базе, но после установки обязательно проверь двумя настоящими аккаунтами. Не отправляй никому секретные ключи Supabase.
