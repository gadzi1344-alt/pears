ОБНОВЛЕНИЕ PEAR — ЖАЛОБЫ И ЗАКРЕПЛЕНИЕ

1. Открой Supabase → свой проект → SQL Editor → New query.
2. Открой файл 7-post-reports-pins.sql из этого архива, скопируй его целиком в редактор и нажми Run. Это расширение существующей базы, оно не удаляет имеющиеся публикации или профили. Старый schema.sql повторно запускать не нужно.
3. В GitHub открой репозиторий Pear. Загрузи с заменой в корень проекта файлы app.js и style.css из архива. Остальные файлы сайта не удаляй и не заменяй. При желании также загрузи 7-post-reports-pins.sql для хранения.
4. Дождись нового деплоя Vercel и обнови сайт. Проверь: у чужого поста меню «⋯» → пожаловаться; в админ-панели появится жалоба. У своего поста меню «⋯» → закрепить в профиле.

В профиле закрепляется один пост; закрепление нового заменит старый. Для жалобы можно выбрать причину и добавить комментарий. Администраторы видят последние 100 жалоб и могут отметить их рассмотренными. При удалении поста связанные жалобы удаляются. Пользователи не могут просматривать список жалоб. Один пользователь может отправить одну жалобу на пост.

Проверь работу с двумя реальными аккаунтами после публикации. Если функция выдаёт ошибку, убедись, что SQL выполнился без ошибок именно в подключённом к сайту проекте Supabase. Не отправляй никому секретные ключи.
