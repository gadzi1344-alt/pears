PEAR — АНИМИРОВАННЫЕ ПОДАРКИ И PEARS
=====================================

ЕСЛИ ПРЕДЫДУЩЕЕ ОБНОВЛЕНИЕ ПОДАРКОВ УЖЕ УСТАНОВЛЕНО
Замени только gifts.js и style.css в корне GitHub-репозитория, сохрани Commit changes и дождись деплоя Vercel. SQL для этой доработки запускать не нужно. Другие файлы не заменяй.

ЕСЛИ ПОДАРКИ ЕЩЁ НЕ УСТАНОВЛЕНЫ
Следуй полной инструкции ниже: понадобится SQL, app.js, gifts.js, style.css и три изображения в assets.

Анимация — лёгкое движение изображений подарков, а не 3D-модель или NFT. Нажми на подарок в коллекции, чтобы увидеть отправителя и время. Время показывается в часовом поясе устройства. Если профиль отправителя больше недоступен, вместо имени появится «Пользователь Pear». При настройке уменьшения движения анимация отключается.

Это обновление для текущего репозитория pears версии 5b527cb. Сайт и база автоматически не изменялись. Сначала сделай резервную копию файлов проекта и базы Supabase. Если в GitHub появились более новые изменения, не перезаписывай их без сравнения.

1. ОБНОВИТЬ БАЗУ SUPABASE
• Открой Supabase → проект, который подключён к Pear → SQL Editor → New query.
• Открой файл 10-gifts-and-pears.sql из архива, скопируй ВЕСЬ текст и нажми Run.
• Дождись успешного выполнения. Если есть ошибка — остановись и сохрани текст ошибки без ключей и паролей.
• Не запускай старый schema.sql: он предназначен для нового пустого проекта.
• После успешного выполнения все существующие профили без кошелька получат 100 Pears. Новые пользователи получат 100 Pears при создании профиля. Повторный запуск скрипта не выдаёт стартовый баланс повторно.

2. ЗАГРУЗИТЬ ФАЙЛЫ В GITHUB
• Распакуй архив. В корне репозитория замени app.js и style.css и добавь gifts.js.
• В существующую папку assets добавь rose.jpg, heart.jpg и star.jpg. Не удаляй остальные файлы в assets.
• Сохрани через Commit changes и дождись успешного деплоя Vercel. SQL и этот файл инструкции в GitHub загружать не обязательно.
• Если браузер показывает старую версию, обнови страницу с очисткой кеша.

3. ПРОВЕРКА ДВУМЯ ТЕСТОВЫМИ АККАУНТАМИ
• Проверь баланс 100 Pears у ранее созданного тестового аккаунта и у нового.
• Открой профиль другого пользователя и нажми «Подарить подарок» → «Роза» (15 Pears). Подтверди, проверь, что баланс отправителя стал 85 Pears.
• У получателя в «Коллекции» скрой подарок. Он должен остаться виден владельцу, но исчезнуть из профиля для другого аккаунта. Затем покажи его обратно.
• Продай подарок. Его владелец получит 13 Pears и подарок исчезнет из коллекции. Повторно продать его нельзя.
• Проверь профиль, ленту, чаты, админку и выход после обновления.

КАК РАБОТАЕТ
• Продажа — обратно системе, не другому пользователю. Комиссия составляет 10% от исходной цены подарка с округлением комиссии вверх до целого Pears. Например, 15 − 2 = 13 Pears. Продажа необратима, с подтверждением.
• Баланс виден только владельцу. Скрытые подарки видны только владельцу; на странице отображаются последние 120 подарков.
• Pears — только внутренняя виртуальная валюта. Покупка за реальные деньги, вывод, пополнение и другие способы заработка не добавлены.
• Картинки подарков — иллюстрации. NFT, блокчейн, 3D-модели и торговая площадка не созданы: это возможное отдельное обновление в будущем.
• Без защиты от множества регистраций стартовый баланс можно получать на разных аккаунтах; перед внедрением реальных денег или публичной экономики нужна отдельная защита от злоупотреблений и аудит.

Проверено локально в тестовом браузере и тестовой PostgreSQL-совместимой базе; конкретный проект Supabase и боевой сайт не проверены. Не отправляй никому секретный ключ Supabase или пароль.
