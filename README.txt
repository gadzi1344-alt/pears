PEAR — ЛОГОТИП ТОЛЬКО ДЛЯ ВКЛАДКИ

Логотип удалён из интерфейса сайта и страницы входа. Он остаётся в файлах для значка вкладки браузера и для значка при добавлении сайта на главный экран телефона. Кнопки навигации, аватарки пользователей и галочки остались. Плюс в мобильном меню — по центру.

Для установки распакуйте архив и загрузите в корень GitHub-репозитория index.html, app.js, style.css, favicon.ico, manifest.webmanifest. Файлы из папки assets загрузите в папку assets репозитория. Сохраните изменения (Commit changes), дождитесь деплоя Vercel и обновите сайт. Не удаляйте существующие api и прочие файлы.

Значок вкладки может обновиться не сразу из-за кеша. На телефоне значок на главном экране появится после использования команды «Добавить на экран Домой» / «Добавить на главный экран» в меню браузера; команда зависит от браузера и телефона.

Настройки базы данных, Vercel и авторизации не изменяются. SQL выполнять не нужно. Эта версия предполагает, что база с профилями и галочками уже настроена из предыдущего обновления.
