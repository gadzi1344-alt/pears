PEAR — ОБНОВЛЕНИЕ: МОБИЛЬНОЕ МЕНЮ, ПРОСМОТРЫ И НИК

Это обновление для уже работающей версии Pear с профилями и галочками. Оно не подключает Supabase автоматически и не меняет настройки Vercel.

1. ОБНОВИТЕ БАЗУ SUPABASE
Сначала рекомендуется сделать резервную копию базы. В Supabase откройте свой проект → SQL Editor → New query. Откройте файл 3-views-and-onboarding.sql из архива, скопируйте весь текст в редактор и нажмите Run. Дождитесь сообщения об успехе.

ВАЖНО: не запускайте заново старые schema.sql или 1-update-database.sql — таблицы уже существуют. Не удаляйте существующие таблицы и данные. В этом обновлении нужен только 3-views-and-onboarding.sql. Если возникла ошибка, остановитесь и сохраните её текст до повторных действий.

2. ОБНОВИТЕ САЙТ
В GitHub откройте репозиторий сайта. Замените в корне файлы index.html, app.js, style.css, favicon.ico, manifest.webmanifest на файлы из архива; файлы папки assets загрузите в папку assets репозитория. Существующую папку api, настройки переменных Vercel и остальные файлы не удаляйте. Выполните Commit changes и дождитесь нового развёртывания на Vercel. Затем обновите сайт в браузере.

3. ЧТО ИЗМЕНИЛОСЬ
• Компактная округлая мобильная навигация; плюс находится по центру. Сохранена адаптация для телефонов и ПК.
• Значок глаза показывает количество уникальных зарегистрированных пользователей, увидевших публикацию в ленте. Просмотр засчитывается, если хотя бы 20% карточки видно около секунды. Повторные просмотры одного пользователя и просмотры своих постов не добавляются. Счётчики начнутся с нуля: прошлые просмотры восстановить нельзя. Это базовый счётчик, не защита от накрутки.
• После первого входа новые пользователи выбирают ник: 3–24 латинские буквы, цифры или _. Уже существующие аккаунты пропускают этот экран. Ник можно изменить в профиле.
• Ограничено масштабирование жестами. Некоторые браузеры, системные настройки доступности и масштабирование через меню браузера могут игнорировать ограничение; полностью запретить масштаб во всех браузерах нельзя.
• Добавлены плавные анимации. При включённом уменьшении движения анимации отключаются.

ПРОВЕРКА
Код интерфейса проверен в тестовом браузере с имитацией Supabase. После установки отдельно проверьте вход новым аккаунтом, уникальность ника и счётчик просмотра между двумя аккаунтами: реальная база в ходе подготовки не изменялась и не проверялась. Не присылайте секретный Supabase key или пароли.
