PEAR — ОТКЛЮЧЕНИЕ ПОДАРКОВ

Это обновление ТОЛЬКО отключает подарки. Вход по виртуальному номеру в этом архиве ещё НЕ реализован. Существующий вход не меняется.

1. Сохрани резервную копию базы и файлов GitHub. Файлы основаны на версии репозитория 554d3ad. Если после неё сайт обновлялся, сначала сравни изменения.
2. В Supabase → SQL Editor → New query скопируй полностью 11-disable-gifts.sql и выполни Run. Он отключает получение, продажу и показ подарков через API и прекращает создание кошельков, но не удаляет сохранённые подарки и балансы.
3. В корне GitHub-репозитория замени app.js и style.css из архива. Сохрани через Commit changes и дождись деплоя Vercel. Другие файлы можно пока не удалять: они не будут подключаться сайтом.
4. Проверь профиль и обычный вход. База и сайт проверены локально на тестах, а не в боевом проекте.

Восстановление подарков — отдельное изменение; не удаляй данные вручную. Никому не отправляй секретный ключ Supabase, токен бота или пароли.
