PEAR — СИНИЕ И ЗЕЛЁНЫЕ ГАЛОЧКИ

Перед установкой сделай резервную копию проекта и базы. Это обновление подготовлено для версии репозитория Pear на момент его создания.

1. SUPABASE
• Открой Supabase → твой проект → SQL Editor → New query.
• Открой 6-badge-colors.sql, скопируй весь текст в SQL Editor и нажми Run.
• Если появится ошибка, остановись и отправь её без паролей и ключей. Не загружай файлы сайта, пока SQL не выполнится успешно.
• Данные существующих подтверждённых профилей сохраняются: их галочки останутся синими.

2. GITHUB
• В корне репозитория замени app.js и style.css файлами из архива.
• Открой папку assets и добавь в неё verified-green.png из папки assets архива. Не удаляй verified.png — это синяя галочка.
• Нажми Commit changes и дождись деплоя сайта. Файл 6-badge-colors.sql нужен для шага 1; загружать его в GitHub необязательно.

3. ПРОВЕРКА
• Открой админ-панель, найди пользователя и нажми «Выдать» или «Изменить».
• Выбери синюю или зелёную галочку. У профиля одна галочка: выбор другого цвета заменяет предыдущий. В том же меню галочку можно убрать.
• При зелёной галочке в профиле отображается «Разработчик проекта Pear». При синей эта подпись не показывается.
• Проверь оба цвета и удаление на тестовых аккаунтах; убедись, что обычный пользователь не может выдавать галочки.

Файлы и база проверены локально в тестовой среде. Самостоятельно в твоём Supabase и GitHub эти изменения не выполнялись. В реальном проекте проверь права существующих администраторов: любой администратор Pear сможет назначить зелёную галочку и подпись разработчика.
