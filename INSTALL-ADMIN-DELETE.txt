PEAR — УДАЛЕНИЕ ПОСТА ПОСЛЕ ЖАЛОБЫ

Перед установкой: должно быть установлено предыдущее обновление жалоб и выполнен 7-post-reports-pins.sql.

1. Открой Supabase → нужный проект → SQL Editor → New query.
2. Открой файл 8-admin-delete-reported-post.sql и скопируй весь его текст в SQL Editor. Нажми Run и убедись, что запрос выполнен без ошибки. Этот SQL не удаляет существующие посты и пользователей.
3. В GitHub в корне репозитория Pear загрузи с заменой файлы app.js и style.css из архива. Остальные файлы не удаляй. SQL также можно загрузить в репозиторий для сохранения.
4. Дождись обновления сайта на Vercel и обнови страницу.

Как работает: администратор открывает жалобу, нажимает «Отметить рассмотренной», затем «Удалить публикацию» и подтверждает. Пост, его лайки, комментарии и все связанные жалобы будут удалены без возможности отмены. Если у поста было изображение, приложение попытается удалить его из Storage. Если не получилось, в админ-панели появится кнопка «Повторить очистку»; до успешной очистки изображение может оставаться доступным по прямой ссылке. Изображение, используемое другим постом, не удаляется.

Права проверяются в базе: обычный пользователь не может удалить чужой пост этим способом. После установки проверь функцию на тестовой публикации. Не отправляй никому ключи Supabase.
